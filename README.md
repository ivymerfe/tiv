## Приоритеты и ассоциативность

- Выражения: унарный `-` > `*` `/` > `+` `-`, левоассоциативные.
- Предикаты: `not` > `and` > `or` > `->`, импликация правоассоциативна.

## Отклонения от `funny.ru.md`

- Условия и предикаты разбираются одним правилом, поэтому `->`, `and`, `or`, `not` допустимы
  и в условиях `if`/`while`, и в предикатах.
- Неоднозначность `(expr) > x` и `(predicate)` решается откатом в `patom`, парсер не строго LL(1).
- `a[i] = v` сразу раскрывается в `a = set(a, i, v)`. Для нескольких индексов используются
  временные `_tN`, в AST появляется узел `Seq`.
- Отсутствующие `requires` и `ensures` дают `null` в AST, значения по умолчанию (`true`/`false`)
  применяются на следующем этапе.
- Слово `function` лексер знает, но грамматика Funny его не использует, парсер его не принимает.
- Пустой ввод считается ошибкой.

## Ограничения type checker

- Временные \_tN от десугаринга объявляются неявно.
- Семантика не запускается при синтаксических ошибках.

# IR

## Формат IR

Функция — список базовых блоков, каждый блок заканчивается терминатором.

## Операнды

- переменная — имя из исходника (параметры, возвращаемые, локальные, `_tN` из дезахарирования);
- временная — `%tN`, создаётся генератором;
- целая константа — `42`, `-1`.

Метки блоков: `entry`, `then3`, `while5`, … Уникальны в пределах функции.

## Заголовок

`func name(p: int, a: int[]) -> (r: int)`

## Инструкции

| Форма                               | Смысл                                            |
| ----------------------------------- | ------------------------------------------------ |
| `d = a`                             | копирование                                      |
| `d = neg a`                         | унарный минус                                    |
| `d = add\|sub\|mul\|div a, b`       | арифметика, `div` — деление с округлением к нулю |
| `d = eq\|ne\|lt\|le\|gt\|ge a, b`   | сравнение, результат 0/1                         |
| `d = load a, i`                     | `a[i]`                                           |
| `d = aset a, i, v`                  | `a[i] = v`                                       |
| `d = len a`                         | `length(a)`                                      |
| `d1, ..., dk = call f(a1, ..., an)` | вызов, k = число возвращаемых значений           |

## Терминаторы

| Форма             | Смысл                                         |
| ----------------- | --------------------------------------------- |
| `jmp L`           | безусловный переход                           |
| `br c, Lt, Lf`    | переход на `Lt`, если `c != 0`, иначе на `Lf` |
| `ret r1, ..., rk` | возврат значений returns-переменных           |
| `trap`            | провал `assert`                               |

## Генерация

- `if`, `while`, `and`, `or`, `not`, `->` в условиях — через ленивые переходы, без материализации булевых значений;
- `while`: `while: cond -> body | endwhile`, `body: ...; jmp while`;
- `assert` без кванторов и formula-вызовов: `br` на `ok` или `fail: trap`; с кванторами и `assume` — спецификация, кода не порождают;
- `requires`, `ensures`, `invariant` и формулы кода не порождают;
- в конце функции — `ret` с returns-переменными.

## CFG

Рёбра берутся из терминаторов, недостижимые блоки удаляются. Опционально DOT: `--cfg-dot FILE`.

## Оптимизации (внутри блока)

| Флаг                                | Действие                                                                        |
| ----------------------------------- | ------------------------------------------------------------------------------- |
| `cprop` (`--no-cprop`)              | распространение констант и копий, свёртка констант, упрощение `br` по константе |
| `algebra` (`--no-algebra`)          | `x+0`, `x*1`, `x*0`, `x-x`, `x/1`, `x==x`, `x*2 -> x+x`                         |
| `dce` (`--no-dce`)                  | удаление мёртвых присваиваний по глобальной живости; `call` не удаляется        |
| `cse` (`--cse`, по умолчанию выкл.) | общие подвыражения в блоке                                                      |

`-O0` отключает всё. Проходы повторяются до неподвижной точки.

## Граф конфликтов

Вершины — временные `%tN`. Ребро между временными, если одна определяется, пока другая жива (для `d = s` ребро `d`–`s` не строится). Раскраска жадная, вершины по убыванию степени. Цвет `rK` — номер регистра. Вывод в текст, опционально DOT: `--ig-dot FILE`.
